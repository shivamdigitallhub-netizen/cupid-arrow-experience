## 💡 About The Project

Cupid Arrow Match is a fun, shareable interactive experience where users enter two names and watch Cupid’s arrow reveal a romantic match result.

It is designed as a **marketing demo**, showing how brands can use interactive storytelling to boost engagement during seasonal campaigns like:

- Valentine’s Day
- Festive promotions
- Brand activations
- Social media engagement

---

## ✨ Features

- 🏹 Animated Cupid arrow interaction
- 💖 Result-based backgrounds & floating emojis
- 📲 WhatsApp Call-To-Action integration
- 🔄 Restart & Share functionality
- 📱 Mobile-friendly responsive layout
- ⚡ Built with pure HTML, CSS, and JavaScript
- 🎯 Client-ready branding for Digital Web Hive
